Privacy and storage

This page is a single file with no server, no analytics and no external requests. The draw happens in your browser.

The match lives after the # in each link. Browsers never send that part to the website, so GitHub only sees a visit to the page.

The match is scrambled, not encrypted. Anyone holding a person's link could decode it, so send each link only to its owner.

Your list and the draw are saved in this browser only, so a refresh doesn't lose them.
